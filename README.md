# Telegram-оркестратор команди (MVP, крок 1)

Перший шматок системи агентів з діаграми: Telegram-бот + AI-оркестратор,
який розпізнає в повідомленнях команди задачі й веде простий беклог.
Деплой-агент, багфікс-агент і презентації додаються пізніше поверх
цього ж каркасу.

## Структура

- `bot.py` — точка входу, обробники команд і повідомлень
- `orchestrator.py` — виклик Claude API, який визначає намір повідомлення
- `storage.py` — сховище задач (JSON-файл `tasks.json`, створюється сам)
- `.env.example` — які змінні середовища потрібні

## Запуск

1. Створіть бота через [@BotFather](https://t.me/BotFather), отримайте токен
2. Отримайте API-ключ на [console.anthropic.com](https://console.anthropic.com)
3. Дізнайтесь свій Telegram user id через [@userinfobot](https://t.me/userinfobot) — і id всіх, кому дозволено користуватись ботом

```bash
pip install -r requirements.txt --break-system-packages
cp .env.example .env
# відкрийте .env і впишіть TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, ALLOWED_USER_IDS

python bot.py
```

## Команди в боті

- `/задача <текст>` — додати задачу вручну
- `/задачі` — показати відкриті задачі
- `/done <id>` — закрити задачу
- Просто повідомлення — оркестратор сам вирішить, задача це, запит статусу чи звичайний чат

## Що далі

- **Деплой-агент**: окремий модуль на базі Claude Code, що запускається по крону
  (GitHub Actions, раз на годину), сканує репозиторій і відкриває PR — без автомерджу
  критичних змін
- **Багфікс-агент**: та сама логіка, але тригер — помилка з логів/Sentry, а не крон
- **Презентації**: команда `/презентація`, що дергає Claude API з pptx-скілом
  і повертає файл прямо в чат
- **storage.py** можна замінити на SQLite чи Notion API, коли JSON-файл стане тісним —
  інтерфейс функцій (`add_task`, `list_tasks`, `complete_task`) лишається той самий,
  `bot.py` міняти не треба
